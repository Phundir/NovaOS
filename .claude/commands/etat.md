---
description: Faire le point sur l'etat du projet en debut de session
---

Reprise de contexte. Lire dans cet ordre :

1. `ROADMAP.md` — tableau d'avancement et limites connues
2. `ARCHITECTURE.md` — carte du code actuel
3. Sortie de `git log --oneline -10`

Puis produire un point court, en prose, couvrant :

- ce qui est termine et valide
- l'etape suivante et les sections de specification qu'elle mobilise
- les limites connues qui pourraient gener cette etape
- tout ecart eventuel entre la roadmap et l'etat reel du code

Ne rien implementer. Ne pas proposer de plan detaille : juste situer.
